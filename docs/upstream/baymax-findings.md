# Baymax upstream findings

This document records reproducible issues or optimization requests found while integrating Baymax.

## Status vocabulary

- `observed`
- `upstream-issue-filed`
- `blocked-upstream`
- `fixed-upstream`
- `closed`

No findings have been recorded yet. A finding must include the exact dependency version or commit, deterministic reproduction, observed behavior, expected behavior, evidence, affected roadmap task, upstream reference, and explicit unblock condition.

When a finding requires an upstream change, dependent implementation tasks remain `blocked-upstream`. Production workarounds are prohibited. After an upstream repair, rerun the reproduction and affected integration checks before changing the status.
